# Ручной переход с CaseVector 1.2.8 на 1.2.9

В версии 1.2.9 изменился ключ подписи. Встроенное обновление версии 1.2.8 не сможет установить этот выпуск. Переход выполняется один раз вручную; после него последующие подписанные выпуски снова смогут устанавливаться через программу.

1. Закройте CaseVector. Найдите папку установленной программы: в ней находятся `CaseVector.exe` и папка `data`.
2. Переименуйте папку программы `CaseVector` в `CaseVector-1.2.8-backup`. Не удаляйте её.
3. Скачайте `CaseVector-Windows-x64.zip` со страницы [выпуска v1.2.9](https://github.com/1-Choose-Goose/CaseVector-Updates/releases/tag/v1.2.9) и распакуйте его рядом с резервной папкой. В результате появится новая папка `CaseVector`.
4. Скопируйте содержимое `CaseVector-1.2.8-backup\data` в `CaseVector\data`. Если в старой папке есть другие файлы данных, созданные вручную, сохраните их отдельно.
5. Запустите новый `CaseVector\CaseVector.exe`. Проверьте, что в окне «О программе» указана версия 1.2.9 и карточки на месте. Сохраните резервную папку до окончания проверки.

Закрытый ключ не нужен пользователям для установки. Папка `data` содержит локальную базу и фотографии; её нельзя заменять пустой папкой из архива.
